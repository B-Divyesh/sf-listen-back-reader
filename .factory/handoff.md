# Listen Back Reader handoff — independent verification

## Status: **FAIL — do not release**

Candidate `0b77d7e150c620c0c4ec48151e1f261f1a590cdf` was independently tested on
2026-08-28 against https://listen-back-reader.sociobot.in. Exact evidence is
in [verification.md](verification.md).

## Release-blocking findings

1. Live **Download extension zip** returns HTTP 404 instead of the archive
   generated by `npm run build`; users cannot install the advertised product.
2. The first required claim command fails from a clean clone because
   `.wxt/tsconfig.json` does not exist until after a build. The claim tests also
   do not use the required browser `/demo` sandbox.
3. Installed-extension `Alt+R` reads a `noarchive` page, bypassing the stated
   no-copy safeguard.

## Verification summary

- Fresh `npm run build` and `npx tsc --noEmit` passed. `npm test` and all claim
  tags pass only after `wxt build` creates its ignored configuration.
- Live first-read and one-click demo gates passed. Demo controls, no local demo
  storage, same-origin requests, desktop/mobile layout, visible focus, and
  reduced motion were independently checked.
- Axe had no serious/critical findings on five live routes; no console/page
  errors or third-party runtime requests were observed.
- The live JS asset exactly matches the candidate, but the release ZIP is
  absent. Route focus, popup target sizes, and HTTP 404 behavior also require
  correction.

## Required next steps

Deploy the ZIP; repair claims for a clean clone and real `/demo` test flow;
honor no-copy signals in keyboard handlers; then fix route focus, popup targets,
real HTTP 404 handling, and vulnerable build dependencies before re-verification.
